Camera frames and weather from data.gov.sg (LTA / NEA). Direction labels are burned into the frames by LTA.

Each direction is scored against that region’s own recorded history, not an absolute threshold — a lamp post in frame would otherwise read as traffic. Until enough readings exist it says so rather than guessing.

This page is a snapshot rebuilt on a schedule, so it lags real time by roughly ten to twenty minutes. The frames shown are the exact ones the verdict was computed from. For a live read, run the app locally.
